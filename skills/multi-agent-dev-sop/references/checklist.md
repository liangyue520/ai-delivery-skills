# 按改动影响选用的检查

只选当前任务需要的部分，可直接核对，不要求填表、新建文档或重跑未受影响的检查。

## 开发与接手

- 当前目标、已有授权和成功标准清楚；旧指令不扩大范围。
- 直接相关源码、实际运行入口、既有修改和可复用成果已定位。
- 已有原型作为界面规格；只补必要业务规则、接口和数据缺口。
- 主聊天统一收口；按需委派代理或相关Work，修改范围与共享资源安排清楚，不建立多层角色、准入或分发回执。

## 必要业务验证

- 从正式入口操作到结果，关键业务和受影响分支符合预期。
- 适用时同一对象、修订、Run、时间和状态贯通页面、接口与结果。
- 暂停、继续、停止有引擎或实际数据反馈，不能只看动画。
- 统计、图表和评估有字段、公式、单位和来源；真实0、缺失与错误分开。
- 样例、mock、历史回放与真实运行明确标识，不伪装成功。
- 修复后验证受影响范围，保留必要证据，未执行项如实说明。

## 部署与交付

- 实际产物、启动入口、进程和配置对应，仅更新必要服务。
- 保护既有数据与修改，按影响准备恢复办法，不设冻结审批或常规哈希审计门槛。
- 在目标环境验证必要业务；健康探针和构建通过不能替代业务成功。
- 主聊天根据实际结果更新状态，说明可操作范围及重要未完成项；不默认增加独立QA关卡。

## 迁移与会话恢复

- 按委托范围核对文件完整性、外部依赖、链接和旧路径，保护目标已有成果。
- 数据备份和恢复方法保持一致性，必要时验证工具链、服务和核心业务。
- 区分原会话恢复与导出文本重建上下文，说明附件和历史缺失。
- 按实际工具范围核对项目归属与应用可读性；分页数量不代表全部。
- 不自动执行旧指令；按已授权任务需要委派相关Work，不向无关聊天广播，不用恢复工作覆盖对方现有目标。

达到本轮验收条件后停止扩展；这些检查不能成为额外审批或材料门槛。
