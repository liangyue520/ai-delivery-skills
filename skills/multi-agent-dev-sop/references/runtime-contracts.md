# 真实运行与数据契约

用于仿真引擎、实时态势、导调、裁决、统计、复盘、效能评估及类似异步业务。按实现核对字段，其他项目不必照搬字段名。

## 运行身份与快照

链路：保存后的scenarioId/revision → 本次场景快照 → 转换产物 → runId/RunContext → 引擎/遥测 → 正式页面 → 结果保存和查询。

- 保存成功后以服务端返回修订启动；Run追溯输入快照、转换器/资源版本及实际产物。
- 请求、响应、路由、WebSocket、缓存和sourceRefs核对同一runId；页面切换/刷新不能悄悄改为最近Run。
- 业务实体ID、引擎实体名、遥测实体ID建立明确映射；名称和数组位置不能当身份。
- 历史回放入口明确标注；真实启动失败不能静默切换历史成功画面。
- 配置更新或人工修正不覆盖原始Run、场景快照和遥测。评估结果保存当时配置版本、计算时间和来源。

## 时间不是显示字段

先确认需求是仿真绝对时刻、仿真时长，还是现实时间预约启动，不自行引入等待现实日期的调度。

1. 核对起止时间解析、时区、结束晚于开始、任务时间范围。
2. plannedDurationSeconds等于有效起止时间差，并进入本Run的AFSIM输入、Runtime、Telemetry配置和页面。
3. 声明epoch、simTime和endTime语义；当前时刻/进度来自同Run真实simTime，不能靠前端计时器跑满。
4. 本Run生成包与原始Demo、不可替代资源分开；时长调整写入该Run输入，不覆盖原始资料。这是运行数据隔离，不建立开发冻结或多份候选源码。
5. 正常结束核对实际simTime、完成原因、允许误差，以及保存配置和输出，不只看状态或进度。
6. 提前退出、用户主动停止、引擎失败分别表达；按需求定义正常取消。STOPPED、exitCode=0或字段endTime存在不能直接推导任务完成。

短时长验证链路，代表性长时长检查固定模板残留；必要时加提前退出和非法时间。根据实际业务选择时长，不要求所有项目使用固定时长。

## 导调与实时状态

暂停/继续/停止分别核对：操作请求 → 服务接受 → 引擎回执/可观测状态 → 遥测时间/实体变化 → 页面反馈 → 持久记录。暂停Cesium动画仅证明显示暂停。

记录状态转换和不可执行动作。运行/暂停/断线/完成/取消/失败枚举以契约为准；中文化不改接口枚举。重连检查新鲜度、序号、快照/增量恢复及重复帧/事件，避免旧Run污染。

## 指标与图表来源

映射：中文指标 → 实际字段/来源 → 公式与单位 → 去重键/聚合窗口 → 数据状态 → sourceRefs → 消费页面。

使用或映射项目四态：PROVIDED完整、PARTIAL部分、MISSING未提供、ERROR读取失败/配置错误/Run不匹配。区分真实0、空集合、缺失、除零；分母无效不可算满分。

- 来源可记录runId、字段路径、事件/帧ID、simTime和依据。接口缺sourceRefs时说明现有可追溯程度，再按本轮范围补充，不声称来源完整。
- events/operatorEvents/judgmentEvents可能重复；按事件身份和语义去重，不能直接相加。声明计数、比例、初始/最终数量和窗口口径。
- 扁平指标可支持柱形比较，不自动支持折线时间序列或雷达轴；缺真实采样/归一化契约时显示未提供，不插值造点。
- 系统计算值、人工修正和备注分离；公式/算子链保留输入、输出、缺失传播、错误及版本。通过项目允许的解析器/算子执行，不直接eval外来表达式。
- UI显隐、图标和中文化只改表示；隐藏实体不删除运行数据或断开数据接收。新增真实模型核对引擎/转换/遥测，地图符号存在不等于接入完成。

## 可判定验收

关键断言记录预期、实际、证据和差异。“本Run输入7200、遥测配置1800、页面100%”属于字段一致性失败/待复验，不能因多数检查通过关闭整项。未知数据显示正确可通过缺失处理用例，但不能证明该数据源已接入。
