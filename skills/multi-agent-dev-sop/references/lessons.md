# 项目经验与适用边界

以下为脱敏后的通用经验，具体实施应依当前项目事实和授权。

- 验证配置、运行状态、实际结果和页面数据是否属于同一次运行，不以多数检查通过掩盖关键失败。
- 区分缺失数据与零值；先核实字段来源和统计口径，再实现图表或评估。
- 区分单个组件启动、完整业务运行和可恢复构建；已有产物不等于当前环境已验证。
- 迁移时核对项目之外的必要环境和状态，保留真实数据，在目标环境验证实际入口。
- 使用最新的职责范围与用户决定；历史记录只作线索。

按影响安排必要验证和恢复措施，不将历史项目细节或旧审批链套用到其他项目。
