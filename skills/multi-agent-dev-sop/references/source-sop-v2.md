# 原2.0长版的兼容入口

此路径保留用于接住旧引用。当前协作在用户授权及宿主规则允许时按需组织代理和相关Work，具体见 [agent-orchestration.md](agent-orchestration.md)。旧版多层管理、冻结审批、哈希审计和强制独立QA交接模板仍停用，不据此恢复2.0流程。

当前开发直接使用 [连续开发流程](workflow.md) 和 [任务指令模板](prompts.md)；按实际任务读取 [业务验证](status-and-evidence.md)、[运行数据规则](runtime-contracts.md) 及 [部署恢复](deployment-recovery.md)。

旧版有用的要求保留在这些现行文件中：复用已有成果、明确业务与数据规则、贯通正式入口、保护真实记录、验证受影响业务、区分实现与实测、说明未完成项以及必要恢复办法。
